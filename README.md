# AniScan Telegram Bot v3.5

Telegram-бот на **Python 3.12**, **aiogram 3**, **Qwen 3.7 Plus** и **SQLite** для определения аниме по кадру с независимой двойной проверкой Qwen.


## Основные возможности v3.5

- Единственный режим поиска через `qwen3.7-plus`.
- Короткий JSON и лимиты ответа для экономии токенов.
- Изображение пользователя уменьшается до 768 px для экономии токенов.
- Веб-поиск и сторонние сервисы изображений полностью удалены.
- Максимум две гипотезы Qwen; каждая независимо перепроверяется отдельным запросом Qwen.
- Неподтверждённый результат не оплачивается: запрос возвращается.
- Старые `extended_credits` мигрируют в `basic_credits` один раз и без потери количества.


## Основные возможности

- Работает только в личных сообщениях.
- Текстовые запросы пользователей не обрабатываются: поиск запускается фотографией.
- В боте один режим поиска без выбора единого.
- Ответ содержит только название, персонажа, точность и короткое описание.
- Первый результат независимо перепроверяется свежим запросом Qwen по исходному кадру.
- Если результат не подтверждён, Qwen получает запрет повторять его, предлагает второй вариант, и он проверяется ещё раз.
- Если две проверки не дали надёжного ответа, запрос автоматически возвращается на баланс.
- Если на фото не аниме, запрос списывается и пользователю выдаётся предупреждение.
- Три предупреждения приводят к постоянной блокировке.
- Подозрительный сексуальный контент сначала проверяется Qwen, пользователь временно ограничивается, а администратор получает кадр и кнопки решения.
- При технической ошибке Qwen списанный запрос возвращается.

## Подписка и пробный запрос

- Для работы нужна подписка на канал из `CHANNEL_ID`.
- После первой подтверждённой подписки пользователь получает один пробный обычный запрос.
- Повторно получить пробный запрос невозможно.
- Если пользователь получил пробник, отписался и вернулся:
  - бот выдаёт предупреждение;
  - пакетные скидки для него отключаются навсегда;
  - цены становятся 10/100/1000 ⭐ и 15/150/1500 ⭐;
  - промокоды, скидка новичка и акции на такой аккаунт не применяются.

## Пакеты Telegram Stars

- 1 запрос — 10 ⭐;
- 10 запросов — 90 ⭐ (скидка 10%);
- 100 запросов — 800 ⭐ (скидка 20%).

Платежи обрабатываются идемпотентно по `telegram_payment_charge_id`.

Старые расширенные балансы автоматически переносятся в единый баланс при первом запуске v3.2. Старые уже созданные счета остаются совместимыми и также начисляют единые запросы.

## Система скидок

Текущая цена пакета уже включает пакетную скидку. Дополнительные скидки складываются поверх неё:

- активный скидочный промокод;
- скидка нового пользователя — 20% на первую покупку;
- разовая скидка за достижение порога пользователей.

**Суммарная дополнительная скидка никогда не превышает 25%.** Цена округляется вверх до целой Telegram Star.

### Автоматические акции

Количество пользователей считается по зарегистрированным записям в локальной базе AniScan:

- 500 пользователей — 10%;
- 1 000 — 15%;
- 5 000 — 20%;
- 10 000 — 25%;
- 50 000 — 25%.

После достижения порога:

- акция запускается один раз;
- право на скидку получают только пользователи, у которых уже была хотя бы одна покупка;
- каждому участнику выдаётся одна разовая скидка этого порога;
- скидка расходуется при следующей покупке;
- администраторы получают отчёт о запуске и доставке уведомлений.

Если несколько скидок доступны одновременно, они складываются, но итог ограничивается 25%. Неиспользованные разовые акции сохраняются в базе и могут применяться по одной в следующих покупках.

## Реферальная система

Пользователь получает персональную ссылку в разделе **«Рефералы»** или по команде `/referrals`.

- Реферер закрепляется, когда новый пользователь впервые запускает бота по ссылке `?start=ref_USER_ID`.
- Самоприглашение запрещено.
- За **каждую** покупку приглашённого пользователя начисляется ровно 15% оплаченной суммы.
- Начисление хранится с точностью до 0.001 звезды, поэтому 15% рассчитываются без потери дробной части.
- Пользователь видит список рефералов, количество их оплат и принесённый доход.
- Внутренний реферальный баланс можно потратить на единые пакеты запросов.

### Важное ограничение Telegram Stars

Обычный Telegram Bot API не позволяет боту произвольно переводить Stars из баланса бота в личный кошелёк пользователя. Поэтому в проекте начисляются **внутренние реферальные звёзды AniScan**. Они имеют расчётную стоимость 1:1 и используются для покупки запросов внутри бота, но не появляются в Telegram-кошельке и не выводятся пользователем.

## Автоматическая рассылка постов канала

Канал из `CHANNEL_ID` одновременно используется как обязательный канал и источник автопостов.

Если в тексте или подписи нового поста встречается отдельное слово `aniscan` без учёта регистра, бот:

1. один раз фиксирует пост в базе;
2. пересылает его всем незаблокированным пользователям;
3. соблюдает пакетную отправку и повторяет запрос после `RetryAfter`;
4. присылает администраторам число успешных и неуспешных доставок.

Чтобы получать `channel_post`, бот должен быть администратором исходного канала. Защищённый от пересылки контент Telegram может не позволить переслать.

## Автовыход из групп и каналов

AniScan не работает в группах и каналах. Если бота добавил человек, чей ID отсутствует в `ADMIN_IDS`, бот автоматически выходит. Добавление администратором проекта из `.env` не вызывает автовыход, однако пользовательские команды всё равно обслуживаются только в личной переписке.

## Админ-панель

Администраторы из `ADMIN_IDS`:

- пользуются поиском бесплатно;
- смотрят фактический баланс Telegram Stars бота;
- смотрят общее число пользователей и прирост за 1/7/30 дней;
- выдают запросы;
- блокируют и разблокируют пользователей по ID или `@username`;
- создают ручные рассылки и награды за действия;
- генерируют промокоды на запросы или скидку;
- добавляют, включают, отключают и удаляют ключи Qwen через админ-панель;
- получают уведомление, когда квота отдельного ключа или всех ключей Qwen исчерпана;
- получают решения по модерации запрещённых изображений.

### Команды

Пользовательские:

- `/start` — запуск и обработка реферальной ссылки;
- `/menu` — главное меню;
- `/referrals` — реферальная статистика и ссылка;
- `/paysupport` — контакт поддержки по оплате.

Администраторские:

- `/admin` — админ-панель;
- `/broadcast` — мастер рассылки;
- `/users` — статистика пользователей;
- `/block @username` или `/block USER_ID` — заблокировать;
- `/unblock @username` или `/unblock USER_ID` — разблокировать.

Telegram не гарантирует получение данных произвольного приватного аккаунта по username. Поэтому надёжный поиск по `@username` работает для пользователей, которые хотя бы один раз открывали AniScan и были сохранены в базе. По числовому user ID поиск надёжнее.

### Управление ключами Qwen

В админ-панели есть раздел **🔑 Ключи Qwen**. В нём можно:

- добавить несколько API-ключей;
- указать отдельный Base URL для ключа из другого workspace;
- посмотреть состояние ключа без показа полного значения;
- вручную отключить, повторно активировать или удалить ключ;
- увидеть последнюю ошибку и количество успешных вызовов.

При ошибке полной квоты ключ автоматически получает статус `exhausted`, администраторы получают уведомление, а бот пробует следующий активный ключ. Временный RPM/TPM-лимит не отключает ключ навсегда: он помещается в паузу примерно на минуту. Если доступных ключей нет, пользовательский запрос не списывается либо возвращается на баланс.

Форматы добавления через панель:

```text
sk-API_KEY
Резерв 2 | sk-API_KEY
Другой workspace | sk-API_KEY | https://WORKSPACE.../compatible-mode/v1
```

Ключи сохраняются локально в SQLite. Полные значения в интерфейсе не отображаются, а сообщение администратора с новым ключом бот пытается удалить сразу после сохранения. Защитите файл базы данных и резервные копии от постороннего доступа.

## Ручные рассылки

Команда `/broadcast` запускает пошаговый мастер:

1. администратор отправляет текст;
2. выбирает проверяемое действие: подписка, поиск, покупка, промокод или нажатие кнопки;
3. выбирает количество запросов награды;
4. указывает 1/10/100 либо своё количество запросов;
5. подтверждает рассылку.

Награда выдаётся одному пользователю один раз. После завершения администратор получает статистику доставок. Промокоды формата `ANISCAN-XXXX-XXXX` автоматически оформляются тегом `<code>`.

## Промокоды

Администратор выбирает:

- тип: запросы или скидка;
- для запросов — количество;
- для скидки — 5/10/15/20/25% или свой процент от 1 до 25%;
- срок: 1/7/30 дней или бессрочно;
- число активаций: 1/10/100 или своё.

Коды создаются в формате:

```text
ANISCAN-AB12-CD34
```

Один пользователь не может активировать один код повторно. Одновременно хранится наиболее выгодная актуальная промо-скидка. Общий дополнительный процент при покупке всё равно ограничен 25%.

## Установка

### 1. Telegram

1. Создайте бота в `@BotFather`.
2. Создайте обязательный канал.
3. Добавьте бота администратором канала, чтобы он мог проверять подписку и получать новые посты.
4. Узнайте числовой ID канала вида `-100...`.
5. Узнайте Telegram user ID администраторов.

### 2. `.env`

```bash
cp .env.example .env
nano .env
```

Минимальная конфигурация:

```env
BOT_TOKEN=...
# Необязательный стартовый ключ. Его можно добавить позже через админ-панель.
DASHSCOPE_API_KEY=...
QWEN_BASE_URL=https://YOUR_WORKSPACE_ID.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen3.7-plus
ADMIN_IDS=123456789
CHANNEL_ID=-1001234567890
CHANNEL_URL=https://t.me/your_anime_channel
SUPPORT_USERNAME=your_username
```

Не публикуйте `.env`, SQLite-базу и API-ключи. `DASHSCOPE_API_KEY` используется как стартовый ключ и при первом запуске сохраняется в таблицу ключей. После этого резервные ключи можно добавлять через админ-панель.

### 3. Linux / VPS / Termux

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python run.py
```

Для Termux:

```bash
pkg update
pkg install python git clang make pkg-config libjpeg-turbo zlib
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python run.py
```

### 4. Docker

```bash
cp .env.example .env
docker compose up -d --build
docker compose logs -f
```

SQLite сохраняется в `./data/aniscan.sqlite3`. Новые таблицы и колонки создаются автоматически, поэтому базу предыдущей версии удалять не нужно. Перед обновлением всё равно сделайте резервную копию папки `data`.

## Ограничение поиска по кадру

Qwen Vision анализирует изображение и независимо перепроверяет результат, но не является специализированным индексом каждого кадра всех аниме. Название и персонаж могут определяться хорошо, однако серия и таймкод иногда будут приблизительными либо неизвестными. Для более точного таймкода можно позже поставить trace.moe первым этапом, а Qwen использовать для дополнительной проверки и оформления ответа.

## Перед публичным запуском

- Проверьте тестовую покупку Stars.
- Убедитесь, что бот — администратор исходного канала.
- Проверьте, что `CHANNEL_ID` является числом, а не ссылкой.
- Настройте Qwen billing и лимит расходов.
- Укажите реальный `SUPPORT_USERNAME`.
- Отредактируйте данные владельца в `PRIVACY.md`.
- Создайте резервную копию `data`.
- Проверьте автопост на тестовом сообщении со словом `AniScan`.
