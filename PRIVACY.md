# Политика конфиденциальности AniScan — шаблон

> Перед публичным запуском укажите данные владельца и контакт. Этот файл является техническим шаблоном, а не юридической консультацией.

## Какие данные обрабатываются

AniScan может сохранять:

- Telegram user ID, username и отображаемое имя;
- дату регистрации и дату последней активности;
- единый баланс запросов и внутренний реферальный баланс/звёзды;
- предупреждения, ограничения и блокировки;
- сведения об оплатах Telegram Stars, заказах и пакетах;
- реферальную связь между пригласившим и приглашённым пользователем;
- суммы реферальных начислений;
- активации промокодов и действующие скидки;
- право на разовые скидки по акциям;
- техническую историю поисков;
- доставку ручных и автоматических рассылок;
- факт получения награды по акции.

## Обработка изображений

Фотографии, отправленные для поиска, передаются в Alibaba Cloud Model Studio (Qwen) для автоматической модерации, первичного распознавания и независимой повторной проверки результата. Сторонние поисковики изображений не используются. Изображения, которые система отметила как потенциально сексуальные, могут быть пересланы администраторам AniScan для ручного решения о предупреждении или блокировке.

Обычные фотографии отдельно в базе проекта не сохраняются. Telegram file ID спорного изображения может храниться в записи модерации.

## Ключи Qwen

Добавленные администратором API-ключи Qwen сохраняются локально в SQLite, поскольку бот должен использовать их для запросов к модели. В админ-панели отображается только маска ключа. Сообщение с новым ключом бот пытается удалить после сохранения. Владелец проекта обязан ограничить доступ к серверу, базе данных и резервным копиям.

## Платежи и реферальные начисления

Оплата цифровых запросов проходит через Telegram Stars. Бот сохраняет платёжные идентификаторы, сумму, пакет и дату, чтобы исключить повторное начисление и разбирать обращения.

Внутренние реферальные звёзды AniScan рассчитываются как 15% от платежей приглашённых пользователей. Они предназначены только для приобретения пакетов внутри AniScan, не переводятся в личный Telegram-кошелёк и не являются выводимым денежным балансом.

Бот не получает данные банковских карт.

## Подписка и действия

Для пробного запроса и отдельных акций бот может проверять текущее членство в обязательном Telegram-канале. Для выдачи наград он может проверять действия внутри AniScan: успешный поиск, покупку, активацию промокода или нажатие кнопки.

## Рассылки

Администраторы могут отправлять сообщения пользователям AniScan. Кроме того, новый пост обязательного канала, в тексте или подписи которого содержится слово `aniscan`, может быть автоматически переслан пользователям бота.

База сохраняет техническую статистику успешных и неуспешных доставок.

## Хранение и защита

Рабочие данные сохраняются в SQLite на сервере владельца. Владелец должен ограничить доступ к `.env`, базе данных, резервным копиям и журналам сервера.
